# Contributing

Explain the concrete failure, affected product/version/platform, minimal proposed change and actual validation. Generalize the invariant; do not publish a workstation's credentials, node addresses, account data, project names or installation history.

Keep audit, authorized repair and installation separate. Changes to system networking/security, broad registry deletion, forced Editor termination, or approval circumvention do not belong in routine setup helpers.

Run `python -m unittest discover -s tests -v` and the current host skill validator. State which operating systems and Agent integrations were actually exercised. Update the version manifest and changelog when publishing a release.

Agent-authored commits should identify the actual model and summarize the problem, fix and tests. Preserve inherited human contributions without claiming they were authored by the Agent.
